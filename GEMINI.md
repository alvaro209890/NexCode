# NexCode Project Instructions

This project is a fork of OpenCode, now being developed as **NexCode**.

## Identity
- **Name:** NexCode
- **Description:** The next-generation open source AI coding agent.
- **Repository:** https://github.com/anomalyco/opencode (original)

## Development Workflow
- Use `bun` for package management.
- Follow the monorepo structure in `packages/`.
- The main CLI entry point is in `packages/opencode`.

## Renaming Strategy
- Gradually rename "OpenCode" to "NexCode" in user-facing strings, documentation, and package names.
- Maintain compatibility with existing plugins if possible.
- Update logos and assets to NexCode branding.
